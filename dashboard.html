⚙️ Configuration requise (une seule fois)

Ce dashboard doit être relié à une base de données gratuite pour que vos ajouts soient visibles par tout le monde sur le site. Ça prend environ 5 minutes :

  1. Créez un compte gratuit sur supabase.com
  2. Cliquez New project, donnez-lui un nom et un mot de passe, attendez ~2 min
  3. Dans le menu de gauche : Table Editor → New table
  4. Nom de la table : catalog_store
  5. Décochez Enable Row Level Security (RLS) pour cette table
  6. Ajoutez 2 colonnes : id (type text, cochez "is primary key") et data (type jsonb)
  7. Menu de gauche : Project Settings → API, copiez Project URL et anon public key
  8. Collez les deux valeurs tout en haut de ce fichier et de boutique.html
✓ Enregistré
