⚙️ Configuration requise (une seule fois)

Ce dashboard doit être relié à une base de données gratuite pour que vos ajouts soient visibles par tout le monde sur le site. Ça prend environ 5 minutes :

  1. Créez un compte gratuit sur supabase.com
  2. Cliquez New project, donnez-lui un nom et un mot de passe, attendez ~2 min
  3. Dans le menu de gauche : Table Editor → New table
  4. Nom de la table : catalog_store
  5. Décochez Enable Row Level Security (RLS) pour cette table (pas besoin de connexion, comme demandé)
  6. Ajoutez 2 colonnes : id (type text, cochez "is primary key") et data (type jsonb)
  7. Sauvegardez la table
  8. Menu de gauche : Project Settings → API
  9. Copiez Project URL et anon public key
  10. Ouvrez ce fichier dashboard.html (et boutique.html) avec un éditeur de texte, collez les deux valeurs tout en haut à la place des valeurs actuelles
  11. Enregistrez, rouvrez la page — c'est fait, tout devient automatique ensuite.

⚠️ Sans mot de passe, n'importe qui connaissant l'adresse de ce dashboard peut modifier le catalogue. Pratique pour toi, à garder en tête si tu partages le lien.
